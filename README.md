# Vertex Models+ (모델 추가)

SillyTavern 확장. 실리태번 목록에 아직 없는 Google Vertex AI 모델 이름을 직접 넣어 쓸 수 있게 해 줍니다.

## 설치

SillyTavern → 확장 → **확장 프로그램 설치** → 아래 주소 입력 → Install just for me

```
https://github.com/nanacorn/st-vertex-models
```

## 처음 들어 있는 모델

`gemini-3.8-flash`, `gemini-4-argon`, `gemini-4-carbon`

## 쓰는 법

API 연결(플러그) → 구글 모델 아래 **모델 직접 넣기** → 모델 이름을 한 줄에 하나씩 적고 **목록에 넣기** → 목록 맨 위 「직접 넣은 모델」에서 선택

SillyTavern 1.19.0에서 확인했습니다.
